# Otu-Zan Laravel API

See [the project README](../README.md) for XAMPP/phpMyAdmin setup, migration notes, and startup commands.

The React app remains in the root project's src directory. This Laravel application provides the authentication and admin rider-directory API on port 5000.

Run tests with `php artisan test`; tests use SQLite in memory and do not modify the configured MySQL database.

Framework documentation: [Laravel 12](https://laravel.com/docs/12.x) and [Sanctum](https://laravel.com/docs/12.x/sanctum).
